# 3-DOF Robotic Arm: PID Control, Simulation and Hardware Prototype

## Project Overview

This project covers the design, simulation and hardware prototyping of a three-degree-of-freedom robotic arm. The mechanical model was designed using Autodesk Fusion 360, exported as STL geometry, and imported into MATLAB/Simscape Multibody for simulation. A physical prototype was also assembled and demonstrated using Arduino-based control.

## Key Contributions

- **Mechanical design:** Designed the robotic arm in Fusion 360 and exported STL files for simulation.
- **Multibody simulation:** Imported the arm geometry into MATLAB/Simscape Multibody to study its mechanical behavior.
- **PID control:** Worked on PID-based control and simulation of the robotic arm.
- **Hardware prototyping:** Built and demonstrated a physical robotic arm prototype.
- **Embedded control:** Used an Arduino-based platform for controlling the hardware.

## Tools and Technologies

- Simulink / Simscape Multibody
